## Projects  

| Project | Skill(s) Covered | Description |
|---------|------------------|-------------|
| **Deploy Scalable Web App on Cloud** | AWS, GCP, Cloud | Full‑stack app (frontend, backend, DB, storage) deployed on a chosen cloud provider with load balancing and auto‑scaling. |
| **Automated Deployment Pipeline** | CI/CD | GitHub Actions workflow that runs unit tests, builds a Docker image, pushes to a registry, and triggers a deployment to the cloud app. |
| **Image Classifier with Deployment** | Computer Vision, Deep Learning, ML | CNN model trained on a labeled image set, saved as a `.h5` file, containerised, and served via a lightweight API. |
| **Build Chatbot with Transformers** | AI/ML, NLP | Conversational bot using BERT/GPT‑2, integrated with a simple front‑end (HTML/JS) for user interaction. |
